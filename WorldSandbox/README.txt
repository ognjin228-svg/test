Песочница миров — как получить EXE

1. Установи Node.js (LTS) с https://nodejs.org, если его нет.
2. Дважды кликни build-exe.bat в этой папке.
3. Подожди 2–5 минут (нужен интернет, скачается Electron).
4. Готовый WorldSandbox.exe появится в папке dist — его можно копировать куда угодно и запускать без установки.

Поиграть сразу без сборки: открой game\index.html в браузере.
